# mechanistic-models-for-cognition
Collection of firing rate models to reproduce cognitive functions. Personal development contribution for the paper "Froudist-Walsh S., Ivanov T.G*., Fantacci T.*, et al. Mechanistic computational models of cognition across scales and species, Biological Psychiatry (2026), doi: https://doi.org/10.1016/j.biopsych.2026.08.017."
Reference repo can be find at the lab page https://github.com/CANNgroup/mechanistic-models-cognition.git
